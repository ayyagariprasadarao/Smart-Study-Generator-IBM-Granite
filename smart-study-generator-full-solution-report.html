The Challenge

Students face an overwhelming flood of scattered, unorganised information — lecture notes, textbooks, research papers, YouTube tutorials, and online resources. Traditional study tools provide only static notes or flashcards, failing to adapt dynamically to individual learning pace or style. Students struggle to find the right material, summarise key concepts, and stay exam-ready. The challenge: move beyond static resources toward an intelligent, adaptive study companion.

Objectives → Implementation Map

1

Fuse Learning Resources

Aggregate content from multiple source types into structured, easy-to-digest study material.

  • Upload PDF, DOCX, TXT, PNG/JPG files
  • Paste raw notes or articles directly
  • 3 built-in sample topic libraries (ML, Data Structures, Thermodynamics)
  • AI summaries at brief / medium / detailed depth
  • Key topic extraction via extract_key_topics()
  • Mnemonic generator for retention
2

Multimodal Input

Accept diverse input types; generate summaries, flashcards, and concept maps.

  • PDF extraction — PyMuPDF (fitz)
  • Image OCR — Pillow + pytesseract
  • DOCX parsing — python-docx
  • AI Flashcard deck — flip, shuffle, difficulty filter
  • Visual Concept Map — node/edge knowledge graph
  • Context-aware AI Tutor chat (RAG-style)
3

Predictive & Agentic Layer

Personalised study plans, topic prioritisation, predictive alerts.

  • AI Study Plan — n-day schedule with Gantt chart
  • Exam Predictor — probability-ranked topics with priority labels (high/medium/low)
  • Predictive alerts — "Focus on Topic X — frequently asked in exams"
  • Weak-area analysis from cumulative quiz history
  • Streak tracking & study-time monitoring
4

Visualise Study Progress

Real-time dashboard — milestones, weak areas, quizzes, performance forecasts.

  • 4 live metric cards — avg score, quizzes taken, streak, study time
  • Weekly activity bar chart (Plotly)
  • Topic performance radar chart
  • Quiz history table with timestamps & scores
  • Weak / strong area progress bars
  • Exam topic probability horizontal bar chart

Role of Agentic AI — IBM Granite

🤖

Single Model, Ten Autonomous Roles

IBM Granite 13B (ibm/granite-13b-instruct-v2) acts simultaneously as summariser, quiz master, study planner, concept mapper, exam predictor, mnemonic creator, and personal tutor. Each role is a self-contained agent task that executes without human curation.

📎

Context Injection — Grounded RAG

The student's own uploaded content is injected into every AI prompt. The tutor and exam predictor receive up to 2,000 characters of personal study material, ensuring responses are grounded in the learner's specific content — not generic knowledge.

📐

Structured Output Contract

Every agent call returns typed JSON — flashcard arrays, quiz objects, study plan days, exam prediction scores. Schema-enforced prompts + _parse_json_list() regex extraction enable direct rendering into charts and cards.

🔁

Adaptive Feedback Loop

Quiz results feed analyze_weak_areas(); diagnostics reshape the dashboard radar, predictive alerts, and exam topic priorities — a true observe → reason → act cycle that personalises over time.

🛡️

Resilient Fallback

_fallback_response() and _default_study_plan() ensure full demo-mode operation if watsonx.ai is unreachable — zero broken UI, zero crashes.

Novelty & Uniqueness

🎯 One Model, All Roles

Unlike tools using separate engines for each task, IBM Granite alone handles summarisation, quizzes, plans, concept maps, predictions, and tutoring — all via schema-enforced prompt engineering.

📚 Content-Personalised AI

Every AI call is grounded in the student's own uploaded content. The system never responds generically — it always reasons about the learner's specific material.

🔄 Self-Closing Adaptive Loop

Quiz performance autonomously reshapes dashboard insights, weak-area focus, and exam topic priorities — no teacher or admin intervention required.

🔮 Predictive Exam Intelligence

The Exam Predictor assigns probability scores and priority levels to topics based on content analysis — functioning as an intelligent exam coach, not just a summariser.
